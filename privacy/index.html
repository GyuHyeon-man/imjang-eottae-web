임장어때(이하 "앱")는 아파트 임장(현장 답사) 기록을 돕는 개인 개발 앱입니다. 운영자는 이용자의 개인정보를 아래와 같이 처리합니다.

1. 수집하는 개인정보와 수집 방법

항목수집 시점용도
이메일 주소회원가입·소셜 로그인(구글·카카오)계정 식별, 기기 간 데이터 동기화
임장 이동 경로(GPS 좌표)·걸음수임장 기록 중(이용자가 시작/종료를 직접 조작하며, 화면 꺼짐·다른 앱 사용 중 포함)임장 기록 저장·표시, 이동 거리 계산

임장 계획 루트(루트 이름·경유지 좌표)이용자가 앱 또는 웹에서 루트를 그려 저장임장 동선 계획 보관, 앱·웹 간 동기화
  • 걸음수는 기기의 신체활동 권한으로 기기 안에서 계산되며, 임장 기록의 일부로만 저장됩니다.
  • 위치정보는 이용자가 임장 시작을 누른 뒤 임장 종료를 누를 때까지만 수집됩니다. 이 시간 동안 화면이 꺼지거나 다른 앱을 사용하는 경우에도 백그라운드에서 동선을 기록합니다. 임장 종료 후에는 위치정보를 수집하지 않습니다.
  • 위치정보는 임장 이동 경로 표시와 거리 계산에만 사용하며 광고에 사용하거나 제3자에게 판매하지 않습니다.

2. 처리 위탁 및 제3자 제공

  • 데이터 보관: Supabase(클라우드 데이터베이스·스토리지, 서울 리전) — 계정·임장 기록·사진·보드 데이터가 저장됩니다.
  • 로그인 연동: Google, Kakao — 소셜 로그인 선택 시 이메일 주소를 전달받습니다.
  • 지도 표시: Kakao 지도 — 지도 화면 표시를 위해 지도 SDK가 동작하며, 이 과정에서 이용자의 개인정보를 운영자가 카카오에 제공하지 않습니다.
  • 실거래가 조회: 국토교통부 공공 API를 서버에서 호출하며, 이용자의 개인정보는 전송되지 않습니다(단지·지역 정보만 조회).
  • 위 위탁 외에 개인정보를 제3자에게 판매하거나 제공하지 않습니다.

3. 보유 기간 및 파기

  • 개인정보는 회원 탈퇴(계정 삭제) 시까지 보유합니다.
  • 계획 루트는 앱의 "저장된 루트" 또는 웹의 "임장 루트" 탭에서 개별 삭제할 수 있으며, 삭제하면 서버에서도 제거됩니다.
  • 앱의 설정 → 계정 삭제를 실행하면 서버(데이터베이스·사진 스토리지·인증 계정)의 모든 개인정보가 즉시 영구 삭제되며 복구할 수 없습니다. 이용 기기에 저장된 데이터도 함께 삭제되며, 기기 데이터 삭제가 일부 실패한 경우에는 앱이 즉시 알리고 완전 삭제 방법(앱 데이터 삭제)을 안내합니다.
  • 법령상 별도 보존 의무가 있는 정보는 해당 기간 동안만 분리 보관 후 파기합니다.

4. 이용자의 권리

이용자는 언제든지 앱 안에서 자신의 기록을 열람·수정·삭제할 수 있고, 계정 삭제로 전체 개인정보 파기를 요구할 수 있습니다. 기타 요청은 아래 연락처로 문의할 수 있습니다.

5. 안전성 확보 조치

  • 모든 서버 통신은 HTTPS로 암호화됩니다.
  • 서버 데이터는 계정별 접근 제어(Row Level Security)로 보호되어 본인 외에는 접근할 수 없습니다.
  • 실거래가·주변정보 조회에 쓰는 외부 API 비밀 키(국토부·카카오 REST)는 앱이 아닌 서버에만 보관합니다. 지도 표시용 카카오 JavaScript 키는 지도 SDK 특성상 앱에 포함되며, 카카오 플랫폼의 도메인·앱 제한으로 오남용을 방지합니다.
